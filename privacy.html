Privacy Policy: ChiruPlays05 Uploader

Last updated: 28 October 2026

ChiruPlays05 Uploader is a desktop tool used only by the owner of the ChiruPlays05 YouTube channel. It is not offered to the public.

What it accesses: through the YouTube API Services, only the owner's own channel, to upload videos, set titles, descriptions, tags, thumbnails, captions, playlists and publishing times, and to read the channel's own analytics.

What it stores: only the OAuth sign-in token, on the owner's own computer. No data from any other user is collected, stored, shared or sold.

Revoking access: at any time from your Google Account security settings (myaccount.google.com/permissions).

The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
